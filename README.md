# proyecto-asir- Papelería Cimas
Documentación del proyecto de PIMA (1º ASIR)

Es una pequeña empresa de 8 empleados que vende material de oficina. Tiene una oficina con 6 ordenadores, una impresora compartida y un servidor pequeño donde guardan facturas y pedidos.

Problemas informáticos:

1. Los ordenadores van lentos: son antiguos y tienen poca memoria RAM 
2. No hay copias de seguridad: si el servidor falla, pierden facturas y datos de clientes.
3. La impresora compartida falla mucho: a veces no aparece en la red y nadie sabe configurarla.

¿Para qué sirve el repositorio?
Sirve para guardar y organizar los archivos y documentos del proyecto en un solo lugar, con un historial de cambios que trabajaremos durante el curso.
